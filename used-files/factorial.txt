IN

CALL :factorial

OUT
HLT

:factorial
POP RAX             ; Извлекаем аргумент n в регистр RAX

PUSH 1
PUSH RAX
JBE :base           ; Если n <= 1, переходим к базовому случаю

PUSH RAX            ; Сохраняем n в основном стеке

PUSH 1
PUSH RAX
SUB                 ; Вычисляем n - 1

CALL :factorial     ; Рекурсивно вычисляем (n - 1)!

MUL                 ; Умножаем сохранённое n на (n - 1)!
RET                 ; Возвращаем результат вызывающей функции


:base
PUSH 1              ; Базовый случай
RET                 ; Возвращаем 1
